# Вычислительная математика

Цикл лабораторных работ по курсу **вычислительной математики**: от линейной алгебры и символьных вычислений до интерполяции, нелинейных уравнений, квадратур и задачи Коши.

Каждый файл `LabN.py` — отдельная лабораторная. Скрипты печатают результаты в консоль; там, где это требуется по заданию, открываются графики.

## Содержание

| Файл | Тема | Что реализовано |
|------|------|-----------------|
| [`Lab1.py`](Lab1.py) | Введение в NumPy / SymPy / SciPy | матрицы, определитель, символьные выражения, СЛАУ, интегралы, графики |
| [`Lab2.py`](Lab2.py) | Матричные вычисления | подматрицы, умножение «вручную» и через `np.dot`, верхнетреугольная СЛАУ, LU-разложение |
| [`Lab3.py`](Lab3.py) | Нормы и QR | евклидова и спектральная нормы, отражения Хаусхолдера, QR и решение СЛАУ |
| [`Lab4.py`](Lab4.py) | Интерполяция | многочлен Лагранжа, первая формула Ньютона (равноотстоящие узлы) |
| [`Lab5.py`](Lab5.py) | Уравнения, интегралы, ОДУ | бисекция, хорды, Ньютон, простые итерации; система 2×2; трапеции и Симпсон; Эйлер и Рунге–Кутта 4 |

## Требования

- Python 3.10+
- зависимости из `requirements.txt`

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
pip install -r requirements.txt
```

Linux / macOS:

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

Из корня репозитория:

```bash
python Lab1.py
python Lab2.py
python Lab3.py
python Lab4.py
python Lab5.py
```

Некоторые задания строят графики (`matplotlib`). Окна нужно закрывать, чтобы скрипт перешёл к следующей задаче. Если графики не нужны (например, в CI), можно задать неинтерактивный backend:

```bash
set MPLBACKEND=Agg
python Lab5.py
```

## Кратко по работам

**Лаб. 1.** Случайные матрицы, транспонирование и определитель; умножение матрицы на вектор; упрощение и дифференцирование выражения в SymPy; решение СЛАУ через NumPy и SymPy; неопределённый и двойной интеграл; пересечение графиков.

**Лаб. 2.** Определитель подматрицы; три способа умножения матриц; генерация невырожденной верхнетреугольной системы; решение СЛАУ через LU (`scipy.linalg.lu_factor` / `lu_solve`).

**Лаб. 3.** Норма вектора и спектральная норма матрицы; обнуление хвоста вектора отражением Хаусхолдера; QR-разложение и решение той же СЛАУ, что в лаб. 2, с проверкой через `numpy.linalg.qr`.

**Лаб. 4.** Интерполяция табличных данных: формула Лагранжа и первая интерполяционная формула Ньютона для равноотстоящих узлов.

**Лаб. 5.** Корни кубического уравнения несколькими итерационными методами; система нелинейных уравнений (метод Ньютона + Якоби); определённый интеграл (трапеции, Симпсон, `quad`, Ньютон–Лейбниц); задача Коши (Эйлер, РК4, `solve_ivp`).
